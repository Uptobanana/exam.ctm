## 二、内科derive-box结构设计（疾病推理链）

内科不适用于中诊的"症状推导型"或"证型展开型"——内科的知识结构是"疾病导向"而非"诊法导向"。需要为内科设计一套专用的derive-box结构。

### 2.1 日常临床推理链（核心）

**适用知识点**：辨证分型知识点（每个病的第2/3个点，如nk-1-2"风寒束表、风热犯表、暑湿伤表证的主症、治法和方药"）

**derive-flow骨架**：
```
病机核心(df-concept) → 辨证铁三角(df-logic) → 分型锁定(df-organ) → 方药配伍逻辑(df-symptom)
```

**derive-step五步**：

| 步骤 | 标题范式 | 内容 | CSS |
|------|---------|------|-----|
| 1 | 一个[病名]，几条路——精准辨证的第一步 | 200-300字。从该病所有的可能表现中，提炼出2-4个辨证分型的"分水岭"关键点。回答：为什么同一个病要用不同方？ | ds-blue |
| 2 | 辨证铁三角——[核心鉴别维度] | 200-300字。提炼该病辨证最关键的2-3个维度(如寒热/虚实/表里/气血/痰瘀)，像"导航GPS"一样锁定分型。 | ds-red |
| 3 | 各证型方药图谱——从证到方的精密匹配 | 300-400字。列出各类型的"症状特征+舌脉+代表方+方义精要"。突出方药之间的鉴别点。 | ds-purple |
| 4 | 最容易开错方的情况——鉴别雷区 | 150-250字。选取2组临床上最容易混淆的证型对，逐条对比鉴别要点。比如风寒vs风热、实证vs虚证。 | ds-orange |
| 5 | 同病异治——不同的病人，同一个病的不同解法 | ≥2个场景变体，覆盖年龄/体质/季节/兼夹证等维度，展示"同病异治"的临床实际。 | ds-orange |

### 2.2 概念阐述型（辅）

**适用知识点**：概念/病因病机知识点（每个病的第1个点，如nk-1-1"感冒的概念及病因病机"）

**derive-flow骨架**：
```
疾病定义(df-concept) → 病机链条(df-logic) → 病位·病性·病势(df-organ) → 辨证总纲(df-symptom)
```

**derive-step四步**：

| 步骤 | 标题范式 | 内容 | CSS |
|------|---------|------|-----|
| 1 | [病名]到底是一个什么病——不只是教科书定义 | 200-300字。从病人体验出发描述这个病，然后落到中医的病机本质——打通生活和理论的隔阂。 | ds-blue |
| 2 | 从病因到病机的因果链——为什么这个人得了这个病 | 200-300字。病因→病理变化→关键病机的完整推导链，用具体生活场景驱动推导。 | ds-red |
| 3 | 病位·病性·病势——三个维度锁定疾病画像 | 200-300字。病位在哪里、病性是什么(寒热虚实)、病程演变的规律(传变/转归)。 | ds-purple |
| 4 | 横看成岭侧成峰——同一种病的不同可能性 | ≥2个场景变体，展示同一疾病的多种可能表现和转归方向。 | ds-orange |

### 2.3 预防/调护型（轻量，少数知识点）

**适用知识点**：预防/调护知识点（如nk-1-4"感冒的预防"）

**derive-box结构**：概念阐述型的简化版——三步derive-step（预防原理→方法体系→个体化推荐），不设derive-flow。

## 六、关键技术风险与规避

| 风险 | 概率 | 影响 | 规避措施 |
|------|------|------|---------|
| **引号冲突**：S5用单引号`'`包裹content，content中的`'`会导致语法错误 | 高 | 阻塞node -c | 所有txt文件中HTML属性统一用双引号`"`；中文引号「」不用`'`；每个文件替换后用node -c立即检查 |
| **ID格式不统一**：有`nk-1-1`和`nk-4a-1`两种格式，正则需要覆盖 | 中 | 替换遗漏 | 用`nk-\d+[a-z]*-\d+`匹配所有变体 |
| **前9单元缺件**：需补齐mnem/mini-quiz/cardQuiz，增量较大 | 中 | 批次A工作量不均衡 | 细化为A/B两批（每批~15点），各有侧重。批次A（1-5单元）先补齐缺件+derive-box，批次B（6-9单元）再跟进 |
| **现有高价值内容被误替换**：后部单元临床案例和陷阱提示丰富 | 低 | 质量倒追 | 提取原始尾部严格验证，替换前确认trailing内容与原始一致 |
| **文件过大**：280KB可能在Write/传输中出现截断 | 低 | 语法错误 | 用Python heredoc写入，每个批次完成后node -c检查 |
