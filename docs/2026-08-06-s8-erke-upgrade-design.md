## 三、儿科特色的内容填充策略

derive-box结构复用内科，但**内容填充体现儿科四大特色**：

### 3.1 "稚阴稚阳"+"纯阳"体质贯穿

儿科所有疾病的病机都围绕小儿体质特点。在各论第2步辨证铁三角中：
- <strong>脏腑娇嫩形气未充(稚阴稚阳)</strong>：易感外邪+易虚易实+易寒易热
- <strong>生机蓬勃发育迅速(纯阳)</strong>：热证多+阳证多+恢复快
- <strong>脾常不足肺常不足肾常虚</strong>：脾肺肾三脏是儿科病主要受累脏腑

### 3.2 "易虚易实易寒易热"传变迅速

儿科病传变快+易虚实转化。各论第2步和第5步中贯穿"传变"意识：
- 实证->虚证(如泄泻伤阴->阴竭阳脱)
- 热证->寒证(如急惊风->慢惊风)
- 第5步同病异治突出"防传变"(早治防变)

### 3.3 肺系"夹痰夹滞夹惊"兼证

儿科感冒/咳嗽等肺系病有独特兼证（夹痰/夹滞/夹惊）。各论第3步方药图谱中：
- 夹痰(肺常不足+痰湿内蕴)：加化痰药(半夏陈皮贝母)
- 夹滞(脾常不足+乳食停滞)：加消食药(山楂神曲莱菔子)
- 夹惊(心肝火旺+热扰心肝)：加镇惊药(钩藤蝉蜕天麻)

### 3.4 脾系"乳食不节"+疳证演变链

儿科脾系病以乳食不节为主要病因+疳证是儿科独有病证。各论第1步分水岭突出：
- 乳食因素(伤食泻/积滞/疳证)
- 疳证演变链：厌食(轻)->积滞(中)->疳证(重)+疳证兼证(眼疳/口疳/心疳等)

## 五、技术风险与规避

以下问题来自S4/S5/S6/S7/S3升级中反复验证的经验，S8同样适用。

### ⚠️ 问题 1：文件截断
**规避**：全程使用 **Python 脚本 + bash heredoc** 方式写入。S8当前60KB，升级后约120-140KB，远超Write限制。

### ⚠️ 问题 2：单元间逗号缺失
**规避**：S8使用双引号 `unit:"..."` 格式，每次替换后修复：
```python
content = content.replace(']}]}{unit:"', ']}]},{unit:"')
```

### ⚠️ 问题 3：JS 字符串中的单引号冲突
**规避**：derive-box内容中避免使用单引号，全部使用双引号或省略。Python三引号包裹构建字符串。

### ⚠️ 问题 4：跨行 content 字符串
**规避**：Python 构建时将整个 content 压缩为一行，替换掉物理换行符。

### ⚠️ 问题 5：语法验证（强制）
**规避**：每批次后执行 `node --check`，通过才继续。

### ⚠️ 问题 6：内容只能做加法
derive-box **新增**在 content 开头，现有内容一字不减。

### ⚠️ 问题 7：字母后缀/特殊ID
S8部分ID带字母后缀（如ek-4a-1、ek-6a-1、ek-7-2、ek-17-2等）。正则匹配用 `.*?content:'` 通配，`re.DOTALL` 跨行匹配，不依赖name精确匹配。

## 六、实现方案

### 6.1 内容插入位置

derive-box 插入在 `content` 字段最前面，在 `<p>` 正文之前：

Python 脚本 + bash 执行。每个 derive-box 在 Python 中构建为字符串，通过正则匹配知识点ID定位插入位置（用 `.*?content:'` 通配，`re.DOTALL` 跨行匹配）。

## 八、质量标准

每个 derive-box 必须满足：
1. **结构完整**：总论4步/各论5步不缺，derive-flow四节点完整
2. **儿科特色**：各论第2步维度名称按病类微调，第3步突出儿科用药特点
3. **体质贯穿**：稚阴稚阳+纯阳+脾肺肾常不足贯穿各论第2步
4. **传变意识**：各论第2/5步体现"易虚易实易寒易热传变迅速"
5. **兼证处理**：肺系第3步必含夹痰夹滞夹惊兼证
6. **乳食因素**：脾系第1步必含乳食不节病因+疳证演变链
7. **疹型鉴别**：传染病第4步必含出疹性疾病鉴别
8. **鉴别有深度**：第4步不仅要列区别，更要解释易混淆点
9. **同病异治**：第5步≥2个场景变体
10. **语法零错误**：每批次后 `node --check` 必须通过
11. **内容不缩水**：只做加法不做减法，现有内容一字不减
