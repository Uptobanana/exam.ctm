## 三、妇科特色的内容填充策略

derive-box结构复用内科，但**内容填充体现妇科四大特色**：

### 3.1 "肾-天癸-冲任-胞宫"轴贯穿

妇科所有疾病的核心病机都围绕此轴。在各论第2步辨证铁三角中，<strong>冲任损伤</strong>是所有病类的首要维度：
- 冲任不固 -> 崩漏/胎漏/子宫脱垂
- 冲任失调 -> 月经不调/不孕
- 冲任虚寒 -> 宫寒不孕/痛经

### 3.2 "女子以血为本"是辨证总纲

女性经孕产乳都以血为用。各论第1步分水岭和第2步铁三角中贯穿"血"的辨证：
- 血虚（经少/闭经/不孕）
- 血热（月经先期/崩漏/经行吐衄）
- 血寒（月经后期/痛经/宫寒不孕）
- 血瘀（痛经/癥瘕/异位妊娠）

### 3.3 经期四维度是月经病辨证特色

月经病的辨证分水岭是"周期-经量-经色-质地"四维度，这是妇科独有的辨证方法（内科无此维度）。每个月经病的derive-box第1步都从此四维度切入。

### 3.4 妊娠病安胎与治病兼顾

妊娠病治法特殊--需兼顾母胎安全。各论第3步方药图谱中：
- 安胎与治病并用（如恶阻止呕+安胎、胎漏止血+安胎）
- 妊娠禁忌药提示（峻下/破血/有毒/滑利药禁用或慎用）
- 强调"有故无殒"（有病则病受之，不伤胎）

## 五、技术风险与规避

以下问题来自S4/S5/S6/S3升级中反复验证的经验，S7同样适用。

### ⚠️ 问题 1：文件截断
**现象**：Write 工具写入超过 ~25KB 的 JS 文件会被截断。
**规避**：全程使用 **Python 脚本 + bash heredoc** 方式写入。S7当前62KB，升级后约120-140KB，远超Write限制。

### ⚠️ 问题 2：单元间逗号缺失
**现象**：替换内容后单元间逗号丢失导致JS语法错误。
**规避**：S7使用双引号 `unit:"..."` 格式，每次替换后修复：
```python
content = content.replace(']}]}{unit:"', ']}]},{unit:"')
```

### ⚠️ 问题 3：JS 字符串中的单引号冲突
**现象**：S7内容字符串使用单引号包裹，derive-box内部出现 `'` 会提前结束字符串。
**规避**：derive-box内容中避免使用单引号，全部使用双引号或省略。Python三引号包裹构建字符串。

### ⚠️ 问题 4：跨行 content 字符串
**现象**：JS 字符串不能物理跨行。
**规避**：Python 构建时将整个 content 压缩为一行，替换掉物理换行符。

### ⚠️ 问题 5：语法验证（强制）
**现象**：语法错误导致科目消失。
**规避**：每批次后执行 `node --check`，通过才继续。

### ⚠️ 问题 6：内容只能做加法
derive-box **新增**在 content 开头（经典原文之前），现有内容一字不减。

### ⚠️ 问题 7：字母后缀/特殊ID
S7部分ID带字母后缀（如fk-2-1a、fk-2-2a）或特殊格式（fk-2x-1）。正则匹配时用 `.*?content:'` 通配，不依赖name精确匹配。

## 六、实现方案

### 6.1 内容插入位置

derive-box 插入在 `content` 字段最前面，在 `<p>` 正文之前：
```
content:'<div class=derive-box>...</div><p><strong>月经</strong>是...</p>...'
```

### 6.2 实现策略

Python 脚本 + bash 执行。每个 derive-box 在 Python 中构建为字符串，通过正则匹配知识点ID定位插入位置（用 `.*?content:'` 通配，`re.DOTALL` 跨行匹配）。

### 6.3 批次策略

按单元分4批，控制在可验证范围：

| 批次 | 单元范围 | 知识点数 | derive-box类型 | 说明 |
|------|---------|---------|---------------|------|
| 第1批 | 单元1-2 总论 | 7 | 概念阐述型 | 生理特点+病因病机，建立模板 |
| 第2批 | 单元3 月经病 | 22 | 疾病推理链（月经病维度） | 月经病是妇科核心，含方剂组成知识点 |
| 第3批 | 单元4-5 带下+妊娠 | 11 | 疾病推理链 | 带下病+妊娠病（安胎特色） |
| 第4批 | 单元6-7 产后+杂病 | 13 | 疾病推理链 | 产后病（多虚多瘀）+杂病 |
| **合计** | | **54**（含方剂组成子项） | | |

注：部分字母后缀知识点（如fk-2-1a方剂组成）内容较短，可能合并简化或并入主知识点derive-box。

每批完成后 `node --check` 验证，预计每批新增 15-25KB。

## 八、质量标准

每个 derive-box 必须满足：
1. **结构完整**：总论4步/各论5步不缺，derive-flow四节点完整
2. **妇科特色**：各论第2步维度名称按病类微调，第3步突出调冲任
3. **冲任轴贯穿**：各论第2步必有冲任损伤维度
4. **经期四维度**：月经病第1步必有周期-经量-经色-质地分水岭
5. **妊娠病安胎**：妊娠病第3步必含安胎与治病兼顾+妊娠禁忌药
6. **鉴别有深度**：第4步不仅要列区别，更要解释易混淆点
7. **同病异治**：第5步≥2个场景变体
8. **语法零错误**：每批次后 `node --check` 必须通过
9. **内容不缩水**：只做加法不做减法，现有内容一字不减
